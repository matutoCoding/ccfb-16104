# 整盘摆盘膨胀推演台

浏览器内运行的面包整盘摆放与醒发/烘烤膨胀推演系统。TypeScript + WebGL2，着色器手写，数据持久化在 IndexedDB。

## 启动

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 生产构建
npm test           # 14 项单元/端到端测试
npx playwright test   # 浏览器渲染冒烟（需先 npm run build）
```

## 六个页面

| 页面 | 能力 |
| --- | --- |
| 产品配方 | 克重/含水量/酵母量/整形（圆球、橄榄、长棍、编辫），醒发与烘烤体积倍数曲线、温湿度、刀口 |
| 盘型 | 平盘、法棍槽盘、带孔网盘、隧道炉网带；内尺寸、挡边高、槽参数 |
| 摆盘编辑 | 拖拽面团、点选精调、行列/错位梅花自动排满，实时显示相邻最小间隙与距挡边间隙 |
| 膨胀推演 | 醒发→烘烤时间轴播放，全时间轴粘连检测，红色标记粘连位置与时刻 |
| 出炉检查 | 逐团长宽高/体积测量、尺寸偏差、粘连标红、整盘合格率 |
| 容量试摆 | Worker 内枚举间距×边距×排布，给出不粘连前提下每盘最大容量 |
| 设置 | 扫描体素、渲染分辨率、光线步进步数 |

## 隐式曲面与渲染

- 每个面团由若干元球拼成：长棍是一串球，编辫是三股螺旋交错球链；片元着色器内直接光线步进求交，不生成三角网格。
- 多项式 `smin` 融合，1-Lipschitz；底面用 `max(f, -y)` 相交实现贴盘，高水量面团按更小的垂直增长指数向四周摊开。
- 均匀网格 DDA 加速：每格登记最多 4 个候选面团，光线只对格内面团求值，60 个面团可实时播放。
- 割口用圆角盒槽从场中减去，随烘烤进度张开；表皮颜色按热剂量从面白→金黄→深棕，顶/侧/底面火分别计算。

## 粘连判定的数学保证（核心）

两面团的场各为 1-Lipschitz 距离场（f<0 在内部）。定义 `g(p)=max(fA(p), fB(p))`，其最小值即两面间隙，`g<=0` 表示零水平集已融合。

体素扫描在规则网格上采样，由 Lipschitz 性质得到严格下界：

```
保证间隙 certifiedGap = 全局最小采样值 − L·(h·√3/2)
```

- `certifiedGap > 0`：任意截面上两面团之间都必有空隙，不是"看起来没粘"。
- `certifiedGap <= 0`：判粘连，再用数值最速下降细化接触点，二分时间轴定位首次接触时刻。
- 扫描域为两 AABB 交集外扩一个体素，并与 AABB 盒距取下界的最大者，兼顾严谨与速度。
